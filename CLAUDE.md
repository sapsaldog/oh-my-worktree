## Build Commands

```bash
# Regenerate Xcode project after changing project.yml
xcodegen generate

# Build from command line
xcodebuild -project OhMyWorktree.xcodeproj -scheme OhMyWorktree -destination 'platform=macOS' build

# Build for release (archive)
xcodebuild archive -project OhMyWorktree.xcodeproj -scheme OhMyWorktree -archivePath build/OhMyWorktree.xcarchive
```

```bash
# Install SwiftLint (required for local builds)
brew install swiftlint

# Run manually
swiftlint lint
```

```bash
# Run tests
xcodebuild -project OhMyWorktree.xcodeproj -scheme OhMyWorktreeTests -destination 'platform=macOS' test
```

## Architecture

**MVVM + SwiftUI** macOS menu bar app (accessory mode, no Dock icon).

- **Models/** — `Repository`, `Worktree`, `WorktreeMetadata`, `AppSettings`, `OhMyWorktreeError`
- **ViewModels/** — `RepositoryListViewModel`, `WorktreeListViewModel` (both `@MainActor`)
- **Views/** — SwiftUI views: `ContentView`, `SettingsView`, worktree/repo selectors
- **Services/** — Business logic: Git operations, external tool launching, persistence, monitoring
- **AppDelegate.swift** — `NSStatusItem` menu bar management, rebuilds `NSMenu` on each open
- **OhMyWorktreeApp.swift** — App entry point, creates `@StateObject` view models and passes to AppDelegate

### Key Services

| Service | Purpose |
|---------|---------|
| `GitCommandExecutor` | Low-level `Process`-based Git CLI wrapper |
| `WorktreeManager` | Parses `git worktree list --porcelain`, add/remove worktrees |
| `RepositoryStore` | Actor-based JSON persistence in `~/Library/Application Support/OhMyWorktree/` |
| `ExternalToolLauncher` | Opens worktrees in iTerm/Ghostty/VSCode/Cursor |
| `GitHeadMonitor` | `DispatchSource` file watcher on `.git/HEAD` for real-time branch detection |
| `UpdaterManager` | Sparkle 2.x `SPUStandardUpdaterController` wrapper |
| `RandomNameGenerator` | `{adjective/city}-{noun}` name generation with collision versioning |
| `WorktreeFileCopier` | Copies files to new worktrees using `.worktreeinclude` patterns (falls back to `.env*`) |

### Data Flow

- Branch names are **never persisted** — always fetched live from `git worktree list --porcelain`
- `WorktreeMetadata` stores only `folderName`, `createdAt`, `lastActivityAt`
- Worktree IDs are deterministic UUIDs derived from path (stable across reloads)
- Menu bar refreshes use 2-second debouncing and Task cancellation to prevent races

## Dependencies

- **Sparkle 2.6+** (SPM) — auto-update framework with EdDSA signing
- **XcodeGen** — generates `.xcodeproj` from `project.yml`
- Requires macOS 14+, Swift 5.9+, Git 2.30+

## Project Configuration

- `project.yml` is the source of truth for build settings (not Info.plist)
- After editing `project.yml`, always run `xcodegen generate`
- Info.plist is regenerated by XcodeGen — edit `project.yml` `info.properties` instead
- Sparkle EdDSA private key is in the macOS Keychain (`ed25519` entry)

## Writing Style

- All public-facing content (GitHub release notes, README, PR descriptions, commit messages) must be written in **English first**.

## Git Workflow

- When creating a PR, use a descriptive branch name (e.g., `fix/repository-store-data-loss`) — never use the raw worktree folder name as the branch name.
- **Before every git commit**, you MUST run `swiftlint lint` and `xcodebuild -project OhMyWorktree.xcodeproj -scheme OhMyWorktreeTests -destination 'platform=macOS' test`. Fix any failures before committing.
