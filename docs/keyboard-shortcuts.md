# Keyboard Shortcuts

All in-app shortcuts are customizable via **Settings > Shortcuts** (⌘,).

## Global

| Shortcut | Action | Description |
|----------|--------|-------------|
| ⌥⇧W | Toggle Menu Bar | Open/close the menu bar dropdown from anywhere (system-wide) |

## Worktree Actions

| Shortcut | Action | Description |
|----------|--------|-------------|
| ⌘N | New Worktree | Create a new worktree with an auto-generated name |
| ⌫ | Remove Worktree | Remove the selected worktree (blocked if uncommitted changes) |
| ⌘⌫ | Force Remove | Remove even with uncommitted changes |
| ⇧⌘⌫ | Quick Remove | Move to Trash immediately without checks |
| ⌘R | Refresh | Reload the worktree list |
| ⏎ | Rename | Edit the selected worktree's name |
| ⎋ | Clear Selection | Deselect the current worktree |

## Repository Actions

| Shortcut | Action | Description |
|----------|--------|-------------|
| ⌘⇧N | Add Repository | Open the repository file picker |
| ⌘⇧↑ | Previous Repository | Switch to the previous repository |
| ⌘⇧↓ | Next Repository | Switch to the next repository |

## External Tools

| Shortcut | Action |
|----------|--------|
| ⌘⇧I | Open in iTerm |
| ⌘⇧G | Open in Ghostty |
| ⌘⇧M | Open in cmux |
| ⌘⇧V | Open in VSCode |
| ⌘⇧C | Open in Cursor |

> Only installed tools appear in the menu. Shortcuts for unavailable tools have no effect.

## App Navigation

| Shortcut | Action |
|----------|--------|
| ⌘O | Open Main Window |
| ⌘, | Open Settings |
| ⌘Q | Quit Oh My Worktree |

## Customizing Shortcuts

1. Open **Settings** (⌘,)
2. Go to the **Shortcuts** tab
3. Click on a shortcut to record a new key combination
4. Conflicts are detected automatically — the conflicting shortcut is highlighted

The global hotkey (⌥⇧W by default) can also be changed in the Shortcuts tab.
